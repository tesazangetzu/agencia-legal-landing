**Tipo:** CREACIÓN
**Área:** decisions/

**Archivos afectados:**
- `.docs/decisions/ADR-001-stack-astro-y-tailwind.md`
- `.docs/decisions/ADR-002-landing-estatico-y-formulario-maqueta.md`
- `.docs/decisions/ADR-003-estrategia-de-estilos-y-tokens.md`
- `.docs/decisions/ADR-004-despliegue-en-vercel.md`
- `.docs/decisions/ADR-005-identidad-visual.md`

**Descripción:**
Se registran cinco decisiones vinculantes: stack Astro 7.4.x + Tailwind 4.3.x + TypeScript strict; landing estática sin backend con formulario maqueta no funcional; estrategia de estilos CSS-first con tokens centralizados; despliegue estático en Vercel sin variables de entorno; e identidad visual editorial jurídica premium con marca placeholder Lex Aurea.

**Motivación:**
Toda decisión arquitectónica debe tener justificación documentada y alternativas evaluadas. Estos ADRs son la base que el Planner y el Executor deben respetar.
